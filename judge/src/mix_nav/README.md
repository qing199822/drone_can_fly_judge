# mix_nav

分为三个包：fly(起飞包)，simple_navigator(导航包)，task_manager(路径点发布包)

## fly包

负责起飞，

该节点运行完毕后会自动退出，防止与节点产生控制权冲突

在fly_takeoff.h文件中可以修改起飞时的各个参数

**问题：有时，无人机起飞高度不一致，或者个别飞机无法起飞（可能是MAVROS的bug）**

## simple_navigator包

实现了控制无人机向目标点移动

可以修改目标容错参数

## task_manager包

负责航点发布，断点记录，追踪时路径点记录

在无人机追踪目标时，该包会每隔三秒记录一次无人机的坐标位置，并存于一个栈中，目标消失后，该包又会弹出栈中的路径点，引导无人机一步一步返回断点位置，这样就实现了返航过程中的避障

launch文件夹中有启动文件和预先设置好储存航点的四个.json文件，launch文件读取json文件时不必考虑复杂的绝对路径，直接写相对路径就好

 ## static_tf

发布相机到机体的静态变换
