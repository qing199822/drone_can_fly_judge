# tracking

该模块负责追踪

根据yolo框的大小判断距离远近，根据yolo框中心点与相机坐标点的相对位置，进行无人机的后续控制，因为我们使用深度相机对目标进行定位，对跟踪稳定性的要求较高，因此我们必须在跟踪算法上下功夫；首先，我们采取了实现了一个tanhx的激活函数，对面积进行计算得到初步速度，然后用一个简单的PD控制器，维持目标框在画面中间，采取IMM多交互卡尔曼滤波器，设置了匀速，匀加速，高机动三种模型，对不同条件下进行状态切换；

在追踪过程中，有IDLE, DETECTING,TRACKING,DASH,LOST几种状态，每个状态中都有自己的控制逻辑

值得一提的是，因为有两个red完全相同，为了不让一架飞机锁定red后另一架飞机无法锁定下一个red，我们加了一个逻辑：遇到red先请求red4，接着请求red5，在tracking 过程中，我们加入话题发布机制，发布时间戳，状态和追踪目标，让bbox坐标计算节点订阅，只有订阅目标与自己解算坐标的目标同属一人才能继续发布坐标到裁判系统中，这样就避免了错误发布导致判定追踪中断

实际上我们对IMM结果和速度输出结果都进行了四层低通滤波，然而转写成cpp后才发现这么做会导致无人机反映过于迟钝，因此我们最终没有采用滤波结果
